# 📱 Tutor de Matemática com Gemini

Um app Flutter que utiliza a API Gemini da Google para resolver e explicar problemas matemáticos passo a passo, com foco em clareza, simplicidade e aprendizado.

---

## 🧠 Descrição

**Tutor de Matemática** é um assistente inteligente que ajuda usuários a resolverem problemas de matemática fornecendo explicações detalhadas em linguagem natural. Basta digitar uma equação ou enunciado e o app utiliza o modelo de linguagem generativa da Google (**Gemini 2.0 Flash**) para retornar uma solução explicada, ideal para estudantes e professores.
